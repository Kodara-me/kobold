# Specifications

Kobold is built spec first (see [CONTRIBUTING.md](../../CONTRIBUTING.md)): each feature is
described here, with numbered acceptance criteria, before it is built. Code and tests cite these
files by name, for example `SPEC-INSTALL.md §6.4`.

| File | Covers |
|---|---|

| [SPEC-SELECTION.md](SPEC-SELECTION.md) | Following series, collections and read lists |
| [SPEC-LIBRARY.md](SPEC-LIBRARY.md) | Browsing the Komga library |
| [SPEC-DEVICES.md](SPEC-DEVICES.md) | Several Kobos, each with its own selection |
| [SPEC-COMICS.md](SPEC-COMICS.md) | Comic conversion with KCC |
| [SPEC-LOCAL.md](SPEC-LOCAL.md) | Files from the computer |

| [SPEC-UNSYNC.md](SPEC-UNSYNC.md) | Removal confirmations |
| [SPEC-KOBO-BOOKS.md](SPEC-KOBO-BOOKS.md) | Books on the Kobo: hide, show, mark, delete, series, backups, undo |
| [SPEC-KOBO-SYNC.md](SPEC-KOBO-SYNC.md) | Komga's own Kobo sync over Wi-Fi |
